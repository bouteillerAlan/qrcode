About this tool

Bulk QR code generation
Paste one value per line to generate dozens of QR codes at once. Each code is rendered at up to 300 px and can be downloaded via CSV export (base64 PNG) or printed directly.
Barcode formats supported
Code 128 (all ASCII text) · Code 39 (alphanumeric) · EAN-13 (13 digits, retail) · EAN-8 (8 digits, small packaging) · UPC-A (12 digits, North American retail) · ITF-14 (14 digits, shipping cartons).
Export & integration
Download a CSV with value, extra columns, and base64-encoded images — ready for Excel, LibreOffice, or any data pipeline. Google Sheets export uses =IMAGE() formulas so QR codes and barcodes render live inside your spreadsheet.
Who is this for?
Inventory managers, warehouse teams, retailers, developers, and anyone who needs to label a batch of products, assets, or serial numbers quickly — without installing software or signing up for a service.

Basic usage

Enter one value per line. Each line generates a QR code and/or barcode for that value.

PRODUCT-001
PRODUCT-002
Hello World

Adding extra columns

Separate additional data with |. You can add as many columns as you like.

SN-00142 | admin | room 3B | spare keyboard attached

Columns appear on the card and are exported in CSV / Google Sheets.

Naming a column inline

Prefix a column value with @name  to give it a label:

SN-00142 | @role admin | @location "room 3B" | @notes spare keyboard attached

The label is shown on the card and used as the column header in exports.

Header line

Put @header> on the first line to name all columns at once, so individual rows don't need @name prefixes:

@header> serial | role | location | notes
SN-00142 | admin | room 3B | spare keyboard attached
SN-00143 | user  | room 1A | docking station missing
  • Position 0 renames the Value column header in CSV/Sheets.
  • Positions 1, 2, … name the extra columns.
  • An inline @name on a row overrides the header for that cell.

Mixing styles

Header names and inline @name prefixes can be combined freely. Inline always wins.

Options

  • QR Code / Barcode — choose which code types to generate.
  • Show main text — display the raw value on the card.
  • Show barcode text — print the value below the barcode.
  • Show ID — numbered badge in the card corner.
  • Show label — QR / format badges on the card.
  • Show columns — show/hide all extra column data on cards and in exports.
